## WEEK-1 PROJECT
# 📄 Resume Website – HTML Only

This project is a **single-page Resume / Portfolio Website** built using **pure HTML**.  
It is part of my **Full Stack Development learning journey** and focuses on strengthening **HTML fundamentals**.

---

## 📌 Project Overview

This resume website includes all the essential sections required for a beginner-level portfolio:

- Personal introduction
- Education details
- Skills list
- Projects showcase
- Contact form

The website is built using **only HTML**, without CSS or JavaScript, to focus on structure and semantics.

---

## 🧩 Sections Included

- **Header / Navbar**
  - Name & short introduction
  - Navigation links using anchor tags

- **Home**
  - Welcome message
  - Project introduction

- **About Me**
  - Brief personal background
  - Learning journey

- **Education**
  - Tabular format using `<table>`

- **Skills**
  - Unordered list of technical skills

- **Projects**
  - Ordered list of completed HTML projects

- **Contact**
  - Simple contact form using inputs and textarea

- **Footer**
  - Copyright information

---

## 🛠️ Technologies Used

- HTML5  

(No CSS or JavaScript used)
